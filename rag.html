Getting the lab ready… a one-time download of about 40 MB. You can read on while it loads.

AThe page reads the PDF

The document is a 4-page customer care handbook. A PDF is made for printing, so the first job is to pull the plain text out of it. The page does that for you — you do not need to read the handbook yourself.

See the PDF

BThe page splits the text into passages

A whole document is too much to search or to hand to a model at once. So it is cut into short passages — here, one per section.

CThe page turns each passage into numbers, and stores them

A small model turns each passage into a list of 384 numbers that stands for its meaning. Passages about similar things get similar numbers. The lists go into a vector database, which is built to find the closest ones fast.

DYou ask a question

Your question is turned into numbers the same way. The database returns the three passages whose numbers are closest to it.

EThe page builds the message for a model

This is the last step of RAG: the passages and your question are put into one message for a model to answer from. Copy it into any chatbot, or open the expected answer below.
